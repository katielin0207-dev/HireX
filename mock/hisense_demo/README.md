# 海信容声招聘测试包

用途：给 HireX MVP 做稳定演示数据，围绕“海信容声（广东）冰箱有限公司 - 现场工艺工程师/制造技术类”场景设计。

岗位依据：
- 海信集团校招方向覆盖研发技术、供应链及制造、职能、营销等序列。
- 海信容声（广东）冰箱 2026 届招聘中出现技术类岗位：现场工艺工程师、IE 工程师、现场质量工程师、设备维修工程师；管理类岗位：采购执行、仓储物流、计划管理。

测试目标：
- 好候选人：能展示高匹配、低风险、建议推进。
- 备选候选人：能展示硬条件达标但短板明确。
- 高风险候选人：能触发经历断层、频繁跳槽、证书过期、信息存疑等风险。
- 错配候选人：能测试筛选系统是否会拒绝“看起来优秀但岗位不匹配”的简历。

装载方式：

```powershell
.\.venv\Scripts\python.exe scripts\load_hisense_demo.py
```

装载后打开 Streamlit 页面，优先测试：

1. 风险识别：选择 `周明远`，应识别高风险。
2. 面试评价：选择 `林嘉豪` 或 `陈雨桐`，粘贴默认面试记录生成评价表。
3. 人才对比：后续 C 模块可直接读取这些候选人做排序和备选推荐。
